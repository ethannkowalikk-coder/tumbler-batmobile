# tumbler-batmobile
A hardware project creating a mini Tumbler Batmobile.
A 3D printed Tumbler Batmobile with electronics.
The printable 3D model files are available on MakerWorld
https://makerworld.com/en/models/1530441-tumbler-batmobile-wcad-edition?from=search#profileId-1604890
